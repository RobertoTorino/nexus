# RPCS3 Manager

Plays PS3 games on the **AMD BC-250** on **Bazzite** with [RPCS3](https://rpcs3.net): installs the RPCS3 build it was
tried with, installs your PS3 firmware through RPCS3, finds your games and adds them to Steam, so a game starts
straight away, on the desktop or from Steam's Big Picture Mode. A log keeps what the app did.

How to install and use it: [RPCS3 Manager in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/apps/rpcs3/).
