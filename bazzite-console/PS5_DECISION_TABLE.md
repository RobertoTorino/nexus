# PS5 Bazzite decision table

Research gathered on 07-11-2026. This is an inventory for a later implement/drop decision, not a recommendation to
install or enable anything. “Possible suite route” describes a potential documentation or app change; it does not
mean the feature belongs in Bazzite Console. No feature in this table has been approved for implementation.

PS5 Linux support is community-maintained and unofficial. Hardware revisions, firmware, kernel, display hardware and
the Bazzite image all affect compatibility. Verify current upstream status and test on the intended hardware before
making a change or claiming support. This research does not provide bootloader or exploit instructions.

## Cross-cutting caveats

The [PS5 kernel issue tracker](https://github.com/ps5-linux/ps5-linux-patches/issues) and [loader issue tracker](https://github.com/ps5-linux/ps5-linux-loader/issues) contain reports involving fan-driver probing, black HDMI output, display mode shifts, wireless timeouts and Pro Bluetooth/xHCI behavior. Treat these as issues reported by users, not confirmed failures on every system or proof that a particular fix is missing.

Potential suite-level work is most plausibly external-tool references, emulator setup help and hardware-specific troubleshooting. Kernel, firmware, custom Mesa, boot/loader and OS-image changes belong to their respective upstream projects or require a separate adoption decision.
