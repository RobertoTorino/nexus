# Decky Loader Manager

Decky Loader Manager installs [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader), the plugin loader
for Steam Game Mode, as a system service on PlayStation 5 hardware running **Bazzite**. It shows the service state
and installed plugins, and links `/home/deck` for plugins written for the Steam Deck. The service is system-wide.

How to install and use it: [Decky Loader Manager in the manual](https://robertotorino.github.io/nexus/bazzite-console-suite/apps/decky/).
