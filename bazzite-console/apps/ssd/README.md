# SSD Check

An optional drive information and filesystem speed test for the Bazzite Console Suite. It shows drives and SMART
information when udisks exposes them. Visibility of the PS5 internal drive and connected drives is not guaranteed.

See [SSD Check in the wiki](https://robertotorino.github.io/nexus/bazzite-console-suite/apps/ssd/).
