# Media

The Media category contains launcher cards, not installable apps. YouTube, Twitch, X, Instagram, Discord, TikTok,
WhatsApp Web and Netflix open fullscreen in Brave Browser's kiosk mode. Spotify opens the Spotify app.

Brave Browser must be installed as a Flatpak to use its website cards. Netflix playback also requires Widevine to
be enabled in Brave; Brave may prompt you to enable it the first time. See
[Brave's DRM instructions](https://support.brave.app/hc/en-us/articles/360023851591-How-do-I-view-DRM-protected-content).
Spotify's [Flathub package](https://flathub.org/en/apps/com.spotify.Client) must be installed to use its card. Each
card checks for its required Flatpak before opening.

The YouTube card uses YouTube's official brand icon; see [YouTube Brand Resources](https://brand.youtube/). The
Twitch card uses the official Glitch logo from [Twitch Brand Assets](https://brand.twitch.com/). Stremio's icon is
from its [Flathub listing](https://flathub.org/en/apps/com.stremio.Stremio). The other service icons come from
[Simple Icons](https://github.com/simple-icons/simple-icons), which releases its icon artwork under CC0.
