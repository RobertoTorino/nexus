# Media Tool

A standalone Qt app for recording BC250 Bazzite Suite installation demos on Bazzite, and for converting the
suite's category icons in a checkout. The suite portal lists it on its Utilities tab. It uses its own Python
environment.

How to install and use it: [Media Tool in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/other-tools/media-tool/).
