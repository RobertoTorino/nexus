# Decky Loader Manager

Brings [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader), the plugin loader for Steam's Game Mode, to
the **AMD BC-250** on **Bazzite**: installs the Decky release it was tried with as a system service, shows whether it
runs and which plugins it has, and links `/home/deck` for plugins written for the Steam Deck.

How to install and use it: [Decky Loader Manager in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/apps/decky/).
