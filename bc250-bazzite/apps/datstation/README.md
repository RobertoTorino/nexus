# Bazzite DatStation

The PlayStation knowledge part of the [DatStation](https://github.com/RobertoTorino/DatStation) Android app, on
**Bazzite**: a front page of tiles that opens a PlayStation quiz against the clock, the history of every
PlayStation console, every system software release, the region codes explained, Sony's user guides and the latest
PlayStation news, and keeps your quiz scores and trophies.

How to install and use it: [Bazzite DatStation in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/apps/datstation/).
