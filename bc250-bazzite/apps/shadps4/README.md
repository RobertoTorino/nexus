# shadPS4 Manager

Plays PS4 games on the **AMD BC-250** on **Bazzite** with [shadPS4](https://github.com/shadps4-emu/shadPS4): installs
the shadPS4 release it was tried with, finds your games and adds them to Steam, so a game starts straight away, on the
desktop or from Steam's Big Picture Mode, and signs you in to shadNet, shadPS4's online service. Extract PKG unpacks
package files (.pkg) into a game folder. A log keeps what the app did.

How to install and use it: [shadPS4 Manager in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/apps/shadps4/).
