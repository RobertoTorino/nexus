# BC250 Suite Releases

The release front end of the BC250 Bazzite Suite: it writes the versions, CHANGELOG entries, pins and portal bump of
a release, and runs the board checks of a portal release. It edits the checkout it lives in, so it is not part of
the portal and has no releases of its own. Committing, tagging and pushing stay with you.

How to use it: [The release front end in the manual](https://robertotorino.github.io/nexus/bc250-bazzite-suite/portal/#the-release-front-end).
